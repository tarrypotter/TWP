PROJECT 01 업무·시뮬레이션
WMS Simulator (LF CENTER SIM)
3D 물류센터 피킹 + 고객 주문 쇼핑몰 + 관리자 관제탑 3-Way 통합 시스템
라이브 웹앱 실행 ↗
Flutter Web Dart Cloud Firestore Firebase Hosting
"원래는 야간 물류 알바를 뛰면서 현장 관리자들이 쓰는 관제 사이트를 만들어보고 싶어서 시도했습니다. 그러다 갑자기 3D로 바코드 찍고 돌아다니는 체험 모드랑 고객 쇼핑몰까지 통째로 연결해 버리자!는 생각이 들어서 하나로 묶어 배포했습니다."
🛠️ 실전 트러블슈팅 (진짜 골치 아팠던 문제와 해결)
⚠️ 문제 1: 160명 AI 작업자 동시 구동 시 30fps 이하 프레임 드랍

작업자 160명이 피킹, 대기, 이동 상태를 매 프레임 연산하여 브라우저 렌더링에 병목이 발생했습니다.

💡 해결: 카메라 시야 및 거리 기반 연산 주기 차등화(LOD)를 적용하여 가까운 작업자만 매 프레임 갱신하고 원거리 작업자는 1초 단위로 갱신하여 60fps를 안정적으로 방어했습니다.

⚠️ 문제 2: 야간수당 1.5배 정산 시 분 단위 부동소수점 오차 버그

밤 10시 경계 전후 분 단위 수당 계산 시 소수점 누적으로 급여 계산이 틀어지는 문제가 있었습니다.

💡 해결: 출퇴근 시간을 초 단위 정수 배열로 환산하고 22:00~06:00 구간만 1.5배 가산하는 순수 정산 함수를 작성해 오차 0원으로 완전 해결했습니다.

PROJECT 02 시스템·가상 OS
DevPortal OS
URL과 ZIP 파일을 브라우저 네이티브 웹앱으로 변환하는 가상 데스크톱 OS
라이브 웹앱 실행 ↗
HTML5 JavaScript JSZip IndexedDB Service Worker
"애플의 자체 OS를 보고 나만의 가상 OS를 만들다가, 호스팅 하나로 다른 프로젝트들까지 다 돌아가게 하면 좋겠다는 생각에 URL과 ZIP을 넣으면 앱으로 자동 변환해 주는 시스템을 완성했습니다."
🛠️ 실전 트러블슈팅
⚠️ 문제: ZIP 압축 해제 후 Blob URL 실행 시 상대경로 CSS/JS 404 에러

Blob URL 내부의 상대경로 파일들이 브라우저 보안 격리로 인해 404를 내며 화면 스타일이 깨지는 현상이 있었습니다.

💡 해결: JSZip 압축 파일 트리를 메모리 상에서 매핑하고, HTML 파서 단계에서 상대경로 태그들을 일대일 메모리 Blob URL로 동적 치환하는 가상 링크 리졸버를 구현해 완벽 구동시켰습니다.

Spring Framework Java Maven Oracle 18c Database MyBatis JSP
"학부 졸업작품으로 진행한 본격 엔터프라이즈 쇼핑몰 프로젝트입니다. 전통적인 Spring MVC와 Oracle 18c RDBMS의 트랜잭션을 깊이 있게 경험하며 견고한 백엔드의 기초를 닦았습니다."
📌 핵심 설계 및 구현 내용
  • Oracle 18c RDBMS 테이블 정규화: 상품 카테고리, 주문 상세, 회원 등급, Q&A/리뷰 게시판 테이블을 3차 정규화하고 자동 증가 시퀀스와 무결성 트리거를 적용했습니다.
  • List 방식 대량 데이터 조회 최적화: 수많은 상품 및 게시판 글을 효율적으로 페이징하고, List 방식 데이터 그리드를 직접 구현하여 조회 성능과 UI 반응성을 검증했습니다.
  • Maven 의존성 관리: 복잡한 Spring 의존성과 JDBC 드라이버 라이브러리 충돌을 Maven pom.xml로 체계적으로 빌드 파이프라인을 구축했습니다.
